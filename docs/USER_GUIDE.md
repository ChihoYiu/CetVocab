# 使用指南 · 薄荷单词 · CetVocab

面向使用者的说明。全部功能**离线可用**，应用**不申请 `INTERNET` 权限**，学习数据只存在你自己的手机上。

> 这是学习辅助工具，不是官方考试系统；与任何考试机构（含 CET 主办方）没有合作关系，不承诺提分、押题或通过考试。

---

## 1. 安装

### 方式一：下载现成的安装包

去 [Releases](https://github.com/ChihoYiu/CetVocab/releases) 下载 `CetVocab-*-debug.apk`：

1. 手机上允许「安装未知来源应用」（设置里搜「未知来源」或「特殊权限」）
2. 打开 APK 安装；若提示「应用未通过安全检测」，选择继续安装
3. 这个包是**调试签名**的预览版：可以直接用，但不能上架商店，安装后的应用名/包名带 `.debug` 后缀，
   将来装正式版会与它并存（相当于两个应用）

### 方式二：自己构建

需要 JDK 17+ 与 Android SDK（platform 36、build-tools 36.0.0）：

```bash
git clone https://github.com/ChihoYiu/CetVocab.git
cd CetVocab
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

> ⚠️ **Windows 用户注意**：仓库路径不能包含非 ASCII 字符（中文、日文等）。
> Android Gradle 插件会直接拒绝构建含中文的路径，请放在例如 `D:\code\CetVocab` 下。
> 想出自带签名的正式包见 [发布签名](RELEASE_SIGNING.md)。

## 2. 五分钟上手

1. **首次启动**：选 CET-4 或 CET-6 → 设每日新词数（默认 20）→ 可选开学习提醒 → 选朗读速度。
   首次进入会先把完整词库写入本机（9,000+ 词），界面上会显示真实进度。
2. **开屏一句**：每次**冷启动**（从桌面重新打开应用）都会先显示一句鼓励的话，约 1 秒后自动进入，
   点一下屏幕可以立刻跳过。它取自本机内置的 398 条原创句子，**避免连续两次显示同一句**，
   不需要联网、也不会在应用内切页面时重复出现。
3. **首页**：看「今日进度」，然后按「下一步」那张卡的按钮做就行——它会告诉你现在该复习还是学新词，以及大约要几分钟。
4. **学习**：卡片默认**不显示释义**；如果这个词有例句，卡片上会先给出**英文例句**（不含中文翻译），
   让你从语境猜词义；想好之后再点卡片看答案，此时才显示释义、例句与例句翻译。
   然后按实际情况选「不认识 / 模糊 / 已掌握」，选完会按记忆规律安排下次出现的时间。
5. **结束**：做完一组或随时退出都可以。退出会用「保存并退出」，下次可以从首页的「继续学习」接着做。

## 3. 各页面在做什么

### 首页（一屏回答四个问题）

| 区块 | 回答的问题 |
| --- | --- |
| 今日进度（环形 + 已学 / 正确率 / 时长） | 我现在到哪了 |
| 下一步（「还需复习 12 个单词，约 4 分钟」+ 一个按钮） | 我现在该做什么 |
| 词汇状态三色条（已掌握 / 学习中 / 未学习） | 我的词库结构如何 |
| 阶段目标（下一个里程碑：50 / 200 / 500 / 1000 / 2000 词） | 离下一个目标还有多远 |
| 学习建议（最多 2 条，带数字依据和一个动作） | 我最近有什么问题、怎么改 |
| 今日一句（每天最多一条） | —— |
| 本周趋势 / 最近学习记录 | 我最近表现如何 |

每个数字都可以点「统计口径」看它是怎么算出来的（见第 4 节）。

### 学习

* 卡片默认隐藏释义，**主动回忆**比直接看答案有效得多。
* **例句提示**：词库里有例句时，卡片在揭晓前会显示这句英文（**故意不显示中文翻译**），
  让你先靠语境判断词义；点开释义后才同时给出释义、例句与例句翻译。
  没有例句的词会回到原来的「先回忆一下，再点击卡片查看释义」提示，不会留一片空白。
* 朗读按钮可读单词；开了「同时朗读例句」后，卡片有例句时会出现第二个朗读按钮。
* 右上角星标可收藏；底部三种评价决定下次复习间隔。
* 「巩固练习」模式下会把刚答错或答得模糊的词插回队列；错题复习同样带例句提示。

### 词库搜索（我的 → 浏览 / 搜索词库，或首页右上角的放大镜）

* 查的是**本机词库**（内置 CET-4 / CET-6 或你导入的词库），**完全离线**，也不会引入词库以外的词条。
* 支持：英文单词精确匹配、前缀匹配、任意位置的包含匹配、中文释义搜索；
  英文忽略大小写，输入前后的空格会自动去掉。
* **拼写相近**：如果拼错了（例如 `recieve`）且没有完全匹配，页面会单独列出一段
  「拼写相近的单词」（编辑距离判定，含 `ie`/`ei` 这类相邻字母写反的情况），
  并明确标注这些是**建议**而不是精确结果。
* 结果行显示单词、音标、词性与简要释义，有例句的还会带一行英文例句；点进去是同一个单词详情页，
  可以在那里朗读、收藏、加入学习。
* 输入有 220 毫秒防抖，结果上限 200 条，查询在后台线程执行，不会卡住输入框。
* 搜索不到时给出空状态提示，而不是空白页。

### 复习（错题本与复习中心）

六个分类：今日待复习 / 未巩固 / 错误次数多 / 最近错题 / 历史错题 / 收藏。可以搜索、按错误次数筛选、
批量重新练习、标记已巩固、删除（删除只影响错题本，不影响学习进度）。

### 考试（闭卷）

* 全程**不显示**释义、例句、搭配与正确答案；题型有英译中、中译英、四选一、拼写填空。
* 例句提示**不适用于闭卷考试**：考试的产品规则就是不给提示，本轮没有为了统一体验而破坏这条规则。
* 中途退出可以保存草稿，之后从首页继续；重复提交有防护。
* 题量、时长在「我的 → 考试设置」里改。

### 统计

累计学习词数、复习次数、连续学习天数与最长纪录、学习时长、正确率、复习完成率、考试平均分、
词库进度、阶段目标、周 / 月趋势与 12 周日历。分母为 0 的指标显示「暂无数据」而不是 0%。

### 我的（设置）

词库级别切换、**乱序刷单词**、每日新词与复习上限、提醒时间、朗读设置与发音服务状态、
主题（浅色 / 深色 / 跟随系统）、动画开关、数据导入导出、清空学习进度、重置全部数据、
隐私说明与词库来源。

关于 **乱序刷单词**（默认关闭）：

* 开启后**每次开始学习时**会把整份队列随机打乱，到期词、未巩固词与新词混在一起出现；
* 关闭时是固定顺序：**先复习到期词 → 再未巩固词 → 最后新词**（这个顺序是有意的，遗忘的代价大于少学几个新词）；
* **正在进行的这一轮不会被中途打乱**——顺序在你按下「开始」时就定好了，退出再进来也保持同一顺序；
* 每张卡左上角仍会显示它属于「今日新词 / 待复习 / 未巩固」，所以打乱后依然知道这个词为什么出现。

## 4. 统计口径（数字为什么是这样）

| 指标 | 口径 |
| --- | --- |
| 学习日 | **凌晨 4 点**为分界。所以熬夜学习算前一天；昨天学过、今天还没开始，连续天数仍然保留 |
| 今日已学 | 今天**首次作答**过的不同单词数（同一个词答对又答错只算 1 个） |
| 今日正确率 | 今天选「已掌握」的次数 ÷ 今天作答总次数；还没作答时显示「暂无数据」 |
| 今日时长 | 答题累计时间，两次答题之间的间隔最多按 2 分钟计入（避免挂着应用刷时长） |
| 已掌握 | 连续答对、复习间隔已拉长到 7 天以上；若之后又变成「模糊 / 不认识」会退回「学习中」 |
| 待复习 | 到期时间已到、且状态不是「已掌握」的词 |
| 复习完成率 | 今天复习过的到期词 ÷ 今天到期的词 |
| 阶段目标 | 下一个词汇里程碑（50 / 200 / 500 / 1000 / 2000 词）；全部达成后目标变成整个词库 |

间隔重复规则是公开可查的：不认识 → 1 天后重来；模糊 → 缩短间隔；已掌握 → 依次 1、3、7、14 天，
之后按难度系数递增，最长 180 天。做错题会自动进错题本，连续答对会陆续标记为已巩固。

## 5. 朗读（TTS）问题排查

朗读使用**系统自带的文字转语音服务**，语言、声音、语速、音调跟随系统设置，应用不覆盖、也不联网。

| 现象 | 原因与解决 |
| --- | --- |
| 提示「系统语音服务不可用」 | 设备没有可用的语音引擎，或引擎被停用。点提示里的「打开系统语音设置」，在无障碍 → 文字转语音输出里选择一个引擎 |
| 提示「缺少英语语音包」 | 引擎没装英语语音数据。点「安装语音包」按引导下载；或换成自带英语的引擎 |
| 提示「当前语音引擎不支持该语言」 | 换一个引擎（同上路径） |
| 读英文口音很怪 | 该引擎没有英语声音，用中文音库读英文。安装英语语音包或换引擎 |
| 改了系统语速但应用没变 | 系统设置的键值个别 ROM 读不到，此时应用使用引擎默认语速，不会强行覆盖。可在应用内用「朗读速度」选慢速 / 常速 |
| 按钮一直是转圈 | 引擎 3 秒内没响应，应用会明确报错并提供重试，不会一直卡住 |

「我的 → 朗读」里有**试听**按钮和本机朗读成功率统计，可以用来判断是引擎问题还是别的。

## 6. 数据与隐私

* 所有学习数据（进度、错题、考试、统计、设置）都保存在应用私有目录（Room 数据库 + DataStore），**不会上传**。
* 应用不申请 `INTERNET` 权限，没有账号、广告、埋点或第三方统计 SDK。
* 想换手机或备份：用「我的 → 数据导出」导出词库 / 学习记录 / 完整备份（通过系统文件选择器保存到你选的位置）。
* 想清空：设置里有「清空学习进度」与「重置全部数据」，都有二次确认。
* 应用内「我的 → 隐私说明」写明了以上内容，与本文一致。

## 7. 词库

* 内置词库的**单词、音标、释义**来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）：
  完整四级 3,849 词、六级 5,407 词（去重后 5,805 个不同单词）。
  四级 / 六级的归属取自该数据源自带的 `tag` 字段，不是本项目对考试大纲的解读。
* **例句**来自 [Tatoeba](https://tatoeba.org)（CC BY 2.0 FR，英文句 + 中文译文，随包内置）。
  实测覆盖：四级 3,230 词（83.92%）、六级 3,695 词（68.34%），去重后 4,054 个词（69.84%）。
  没有合适句子的词**保持空字段**并隐藏区块，不会显示自造或套用同一句式的例句。
  逐句来源记录在 [EXAMPLE_SENTENCE_SOURCES.tsv](EXAMPLE_SENTENCE_SOURCES.tsv)，实测数字见
  [WORD_PACK_VALIDATION.md](WORD_PACK_VALIDATION.md) 附录 B。
* ECDICT 不提供**常见搭配**，因此该字段仍为空——**界面会隐藏空区块，不会显示假数据**。
* 想用自己的词库：支持 JSON / CSV 导入，字段定义见 [词库导入格式](WORD_PACK_FORMAT.md)。
  导入前会先校验并给出预览（新增 / 更新 / 跳过 / 错误数），确认后才写入，失败会整体回滚。
* 第三方内容与许可的完整声明见 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)。

## 8. 常见问题

**问：为什么首页的「下一步」有时是复习、有时是新词？**
答：优先级是「先复习到期词 → 再学新词（不超过你设的每日目标）→ 最后巩固错题 → 全部完成」。
遗忘的代价远大于少学几个新词，所以复习永远排在前面。

**问：为什么「今日已学」和「作答次数」不一样？**
答：「今日已学」数的是**不同的词**，一个词反复练只算 1 个。

**问：建议为什么有时只有一句「目前数据有限」？**
答：作答少于 20 次或活跃不足 3 天时，任何结论都不可靠，所以应用明确说明数据不足，而不是硬凑建议。

**问：提醒没响？**
答：Android 13+ 需要通知权限；另外部分手机会限制后台任务，可在系统设置里允许本应用后台运行。

**问：能装到平板 / 折叠屏上吗？**
答：可以，`minSdk 26`（Android 8.0）以上都能装，布局跟随屏幕宽度与字体缩放。
