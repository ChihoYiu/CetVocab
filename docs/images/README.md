# 截图目录

这个目录预留给 README 的界面截图。**目前还没有图片**——需要你在真机或模拟器上截图后放进来。

## 需要哪些图

| 文件名 | 截图内容 | 建议 |
| --- | --- | --- |
| `home.png` | 首页：今日进度环 + 「下一步」卡 + 词汇状态三色条 + 阶段目标 | 竖屏、浅色主题 |
| `study.png` | 学习卡：释义隐藏状态，能看到朗读按钮与「美式/英式」已移除后的样子 | 可以再配一张显示释义的 |
| `insight.png` | 首页下方的学习建议卡与每日激励一句 | 需要有学习数据才会出现 |
| `review.png` | 错题本 / 复习中心，展示筛选与列表 | 有错题时截图 |
| `exam.png` | 闭卷考试进行中（题号、剩余时间、选项） | 注意别泄露正确答案 |
| `stats.png` | 学习统计 + 「统计口径」弹层 | 这张最能说明数据可信度 |

补充建议：

* 深色主题各再来一张也很有用（文件名如 `home-dark.png`）。
* 截图前把状态栏时间清一下无所谓，但**不要**出现真实姓名、账号等个人信息。
* 宽度建议 1080px 左右，PNG 格式；单张控制在 500 KB 以内，避免仓库膨胀。

## 放进来之后

把根目录 `README.md` 里「界面」一节的那段说明替换成图片引用，例如：

```markdown
| 首页 | 学习 |
| --- | --- |
| ![首页](docs/images/home.png) | ![学习](docs/images/study.png) |
```

## 为什么现在是空的

截图必须来自真实运行的界面。本项目拒绝用设计稿或占位图冒充真实截图——README 里宁可写明「待补充」。
